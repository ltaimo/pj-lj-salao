# Android

A app Android futura deve reutilizar a Web App via Capacitor.

Package ID provisório:

```text
mz.co.pjlj.salon
```

Regras:

- Gerar Android App Bundle `.aab`, nao apenas APK.
- Manter regras de negocio no backend.
- Proteger upload key e release signing.
- Preparar target API 36 ou superior antes de publicacao.
- Adicionar plugins nativos apenas quando necessarios: camera, barcode, push, impressao, biometria e deep links.
